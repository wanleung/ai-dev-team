# Fedora Retiring Deepin Desktop Packages Over Security Concerns

The Fedora Project has voted to retire all Deepin desktop environment packages from its repositories following a year-long security review. The decision mirrors a similar move by SUSE approximately one year ago, when the enterprise Linux distributor discontinued its Deepin packages over comparable security concerns.

The Fedora Engineering and Steering Committee (FESCo) opened a security review request for Deepin packages one year ago, following security revelations by SUSE and openSUSE. During that period, Fedora developers encountered difficulties contacting Deepin package maintainers. The review process was also complicated by a lack of clear policy outlining security and maintenance expectations.

During today's Fedora Engineering and Steering Committee (FESCo) meeting, the committee voted to retire all Deepin packages with a note referencing the underlying FESCo ticket. The committee also directed release engineering not to unretire the packages if future requests are made unless they pass review again.

## Year-Long Review Process

The security review began one year ago when FESCo opened a ticket to conduct a Deepin security assessment following revelations by SUSE and openSUSE. During that time, Fedora developers encountered difficulties reaching some Deepin package maintainers. Complicating the matter was a lack of clear policy outlining expectations for package security and maintenance standards.

The Deepin desktop environment, developed by the Chinese Linux distribution Deepin, has faced increased scrutiny from multiple Linux distributors over security practices. SUSE's decision to remove Deepin packages in 2025 established a precedent that Fedora has now followed.

## Impact on Fedora Users

Users currently running the Deepin desktop environment on Fedora will need to transition to alternative desktop environments. The removal means Deepin packages will no longer receive updates through Fedora's standard package management channels.

The Deepin desktop is recognized for its distinctive visual design and user-friendly interface, which has attracted users seeking alternatives to traditional Linux desktop environments like GNOME, KDE Plasma, and XFCE. However, security concerns and insufficient maintenance activity ultimately outweighed the aesthetic and usability benefits in Fedora's assessment.

## Migration Options

Fedora users currently running Deepin should consider migrating to supported desktop environments. Popular alternatives available in Fedora's repositories include GNOME (the default), KDE Plasma, Cinnamon, MATE, and XFCE. Users can install these environments alongside their existing setup before removing Deepin packages.

## Broader Implications

Fedora's decision reflects a broader trend within the Linux community toward prioritizing security and active maintenance over package diversity. Major distributions are increasingly willing to remove packages that do not meet their standards, even when those packages offer unique functionality or appeal to niche user bases.

For the open-source community, this development underscores the importance of sustained maintenance and security responsiveness. Projects that fail to demonstrate active stewardship risk losing distribution support, which can significantly impact their user base and adoption.

The removal process will be implemented in upcoming Fedora releases, giving users time to transition to alternative desktop environments before Deepin packages are fully retired from the repositories.
